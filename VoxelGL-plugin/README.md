# VoxelGL-plugin

VoxelGL renderer'ının Android eklenti uygulaması. [MobileGlues-plugin](https://github.com/MobileGL-Dev/MobileGlues-plugin) çatalıdır (LGPL-2.1).

Genel bilgi, hedefler ve yol haritası için `VoxelGL-docs/README.md` dosyasına bakın.

Derleme: `./gradlew assembleRelease` (Android SDK/NDK gerekir). Not: depodaki `keystore.jks` orijinal projenin imzasıdır; kendi sürümünüzü yayımlarken kendi anahtarınızı kullanın.
