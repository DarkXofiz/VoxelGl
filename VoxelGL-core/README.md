# VoxelGL-core

VoxelGL renderer'ının C++ çekirdeği; OpenGL ES 3.x üzerinde çalışan bir GL uygulaması (en iyisi 3.2, en az 3.0). [MobileGlues](https://github.com/MobileGL-Dev/MobileGlues) çatalıdır (LGPL-2.1).

Genel bilgi, hedefler ve yol haritası için `VoxelGL-docs/README.md` dosyasına bakın.

Shader geliştiricileri için: MobileGlues makroları (`MG_MOBILEGLUES`, `MG_MOBILEGLUES_VERSION`) uyumluluk için aynen korunmuştur.

Hata ayıklama: `Ignore shader/program error` seçeneğini açın ve `/sdcard/MG/latest.log` dosyasına bakın.
